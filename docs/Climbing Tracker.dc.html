2aGrade picker anatomy
Two taps. Colour, then outcome.
Everything between is defaulted. The outcome button is the save, so there is no separate Log button to find with chalky fingers.
01
Gym once per session
Tap the gym chip: Arkose, Block'Out, Vertical Art, The Roof, or one you've added. Its profile maps tags onto Font.
02
Tag first — colour or number
Colour gyms get one 56pt swatch per band, in that gym's order (6 or 7). Block'Out swaps to a B0–B15 grid; B-grades are exact, so the fine row disappears.
03
Fine row is optional
Defaults to the middle of the band. Nudge if the setter's grade is known. Canonical grade is stored; display follows preference.
04
Outcome commits
Flash, Send or Project writes the row locally, resets tries to 1 and keeps the colour. Confirmation is one line of mint text that fades in 1.8s.
